# KKCalendar

タスクトレイに常駐する日本のカレンダー。**祝日**（振替休日・国民の休日を含む）と**六曜**がひと目でわかります。
Windows 標準のカレンダーのポップアップには日本の祝日が出ないので、それを補うためのツールです。

```
 11月13日 金曜日
 2026年・令和8年・友引
 次の祝日　11月23日（月）勤労感謝の日・あと10日
 ─────────────────────────────────
 2026年11月  令和8年          今日  ˄  ˅
  日    月    火    水    木    金    土
  1     2    [3]    4     5     6     7      ← 日付の下の行が六曜
 ...
 ─────────────────────────────────
 3日（火）  文化の日
 23日（月） 勤労感謝の日
```

ポータブル版は `dist\KKCalendar.exe` の単一ファイル（約 200 KB）で、どこにコピーしてもダブルクリックで動きます。
Windows 10/11 に標準で入っている .NET Framework 4.8 を使うので、**ランタイムのインストールは不要**です。
この exe は `build.bat` の生成物で、git には入れていません。`build.bat` を一度実行すれば作れます。

## 使い方

`KKCalendar.exe` をダブルクリックすると、カレンダーが画面右下に一度表示され、その後はタスクトレイに常駐します。

| 操作 | 動作 |
| --- | --- |
| トレイアイコンを左クリック | カレンダーを表示 / 閉じる |
| トレイアイコンを右クリック | メニュー：カレンダーを開く / 祝日データを更新 / 六曜を表示 / スタートアップに登録 / 終了 |
| ホイール、`←` `→`、`PageUp` `PageDown` | 月を移動 |
| `Home` または「今日」 | 今月に戻る |
| グレーの前月・翌月の日付をクリック | その月へ移動 |
| 日付にマウスを乗せる | その日の祝日名と六曜を表示 |
| `Esc` またはカレンダーの外をクリック | 閉じる |

- トレイアイコンには**今日の日付**が描かれます。今日が祝日ならアイコンが赤くなります。アイコンにマウスを乗せると、今日の六曜と次の祝日が表示されます。
- **Windows 11 では新しいトレイアイコンが「^」（隠れているインジケーター）の中にしまわれます**。常にタスクバーに出しておきたい場合は、
  アイコンを「^」の中からタスクバーへドラッグするか、「設定 → 個人用設定 → タスク バー → その他のシステム トレイ アイコン」で KKCalendar をオンにしてください。
- exe をもう一度ダブルクリックしても 2 つ目は起動せず、すでに動いているほうのカレンダーが表示されます。
- システムのライト / ダークモードとアクセントカラーに追従します。Windows 11 では半透明のアクリル背景になります。
- 「スタートアップに登録」は「スタートアップ」フォルダーにショートカットを置くだけです（レジストリは書き換えません）。起動時はトレイに入るだけで、ポップアップは出ません。
- 設定（`KKCalendar.ini`）とダウンロードした祝日データ（`syukujitsu.csv`）は exe と同じフォルダーに置きます。
  exe が書き込みできない場所（Program Files など）にある場合は `%LOCALAPPDATA%\KKCalendar` に置きます。

## データの出どころと正確さ

### 祝日

- **内閣府が公開している「国民の祝日」CSV に含まれる年は、CSV を正とします**（現在は 1955〜2027 年）。プログラムに 1 部内蔵しているので、
  オフラインでも使えます。右クリックメニューの「祝日データを更新」で内閣府から最新版をダウンロードし直せます（メニューには、いまのデータが何年分まで入っていて、いつ更新したかが表示されます）。
  春分の日・秋分の日は前年 2 月の官報で正式に発表されるので、毎年春以降に一度更新すれば翌年の公式データが手に入ります。
- **CSV に含まれない年（1948〜1954 年、2028〜2100 年）は「祝日法」の規定どおりに計算します**。ハッピーマンデー、振替休日、国民の休日、
  2019〜2021 年の特例もすべて反映済みです。春分・秋分は天文計算の結果を使います。将来法律が変わった場合（祝日の新設など）、
  規則で計算する部分はそれを知りませんが、内閣府の CSV には反映されるので、更新すれば追従できます。
- 1955〜2027 年について、規則による計算と CSV を**1 日ずつ照合し、完全に一致することを確認済み**です（`test.bat`）。CSV で単に「休日」と書かれている日は、
  カレンダー上では「振替休日」か「国民の休日」かを具体的に表示します。

### 六曜

六曜 ＝（旧暦の月 ＋ 旧暦の日）÷ 6 の余りなので、要になるのは旧暦です。旧暦の各月は「朔」（新月）の日から始まり、
月の番号は「中気」で決まります。どちらも**日本時間**で天文現象の時刻を正確に求める必要があります。

- `tools/gen_astro.py` が NASA JPL の DE440 暦を使って 1900〜2100 年の旧暦の月表をあらかじめ計算し、プログラムに埋め込みます。実行時は表を引くだけで、ネットにはつなぎません。
- **検証**：同じアルゴリズムを北京時間に切り替えると中国の農暦のルールになるので、香港天文台が公開している 1901〜2100 年の農暦表と比較しました。
  2400 か月あまりのうち違ったのは 5 か月だけで、すべて理由が説明できます。1914・1916・1920 年は当時の中国が（東経 120 度ではなく）北京の地方時を使っていたため、
  2057・2097 年の 2 回は朔が真夜中の 2 分以内に当たり、将来の地球の自転（ΔT）の予測しだいで結果が変わるためです。
- **2033 年問題**：通説に従って「閏11月」としています。
- **まだ不確かさが残る月**：2051 年 11 月と 2074 年 8 月。この 2 回の朔は日本時間の 0 時まで 1 分を切っており、
  ΔT の予測が少しずれるだけで 1 日ずれます。この 2 か月の六曜は、まるごと 1 つずれている可能性があります。

## 改造とビルド

```
src/Core/HolidayRules.cs    祝日法に基づく祝日の計算（純粋なロジック）
src/Core/HolidayBook.cs     内閣府 CSV を優先し、なければ規則で補う。CSV の解析
src/Core/Kyureki.cs         旧暦の表引き、六曜
src/Core/AstroTables.g.cs   旧暦の月表＋春分・秋分（gen_astro.py が生成。手で編集しない）
src/Data/syukujitsu.csv     内蔵の内閣府 CSV（Shift_JIS のまま）
src/PopupWindow.xaml(.cs)   カレンダーのポップアップ
src/TrayIcon.cs             トレイアイコンとメニュー。アイコンの描画は TrayIconPainter.cs
src/App.xaml.cs             常駐、多重起動の防止、日付の切り替わり、更新
tests/                      単体テスト
tools/gen_astro.py          旧暦表の生成（--check で香港天文台の表と照合）
tools/make_icon.py          exe のアイコンを生成
```

- .NET SDK が必要です（net48 のプログラムのビルド用。PATH 上にあっても、`%LOCALAPPDATA%\Microsoft\dotnet` にあっても構いません）。
- ビルド：`build.bat` をダブルクリックすると、`dist\KKCalendar.exe` ができます（実行中の場合は先に終了させます）。
- テスト：`test.bat` をダブルクリック。
- 内蔵の祝日データを差し替える：内閣府の CSV をそのまま `src/Data/syukujitsu.csv` に上書きし、テストを通してからビルドします。
- 旧暦表の再生成（ふつうは不要）：
  ```
  python -m venv .venv
  .venv\Scripts\pip install -r tools\requirements.txt
  .venv\Scripts\python tools\gen_astro.py --check
  ```
  初回は約 30 MB の暦データと 200 年分の香港天文台の年表を `tools/cache` にダウンロードします（git には入れません）。
- 開発用のコマンドラインオプション：`KKCalendar.exe --screenshot out.png [2026-09] [dark|light]` でポップアップを表示してスクリーンショットを保存、
  `--tray-preview out.png` で各サイズのトレイアイコンを出力、`--update-check out.txt` で更新処理を実際に 1 回実行、`--exit` で実行中のものを終了します。

データの出典：祝日 — 内閣府「国民の祝日について」（https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html ）、
暦 — NASA JPL DE440、検証用 — 香港天文台「公曆與農曆日期對照表」。
