# CalcBar

一条 Spotlight 风格的计算条。**算式按 Python 写，math 的函数不用写 `math.`**。

```
🔍  27*27          = 729
🔍  2**3           = 8
🔍  tanh(2)        = 0.9640275800758169
🔍  (1+2)*(3+4)    = 21
🔍  sqrt(2)/2      = 0.7071067811865476
```

绿色版是 `dist\CalcBar.exe` 单个文件，拷到哪儿都能双击运行，**不用装 Python**、不写注册表。
Python 3.12 的运行时打包在里面（所以有 18 MB）。这个 exe 是 `build.bat` 的产物，**不进 git**
（18 MB 的二进制塞进版本历史就再也拿不掉了）——自己跑一下 `build.bat` 就有。

> 窗口是无边框的，所以**任务栏不会出现按钮**（和 Spotlight 一样）。exe 文件本身有图标；
> 如果资源管理器里显示的是白板，是 Windows 图标缓存没刷新，换个文件夹看或重启资源管理器即可。

---

## 怎么用

双击 `dist\CalcBar.exe`（或者装了 Python 的话双击 `run.bat`），输入框自动获得焦点，
**边打边出结果**，灰色的 `= 结果` 就跟在算式后面。

| 按键 | 作用 |
| --- | --- |
| `Enter` | 把结果复制到剪贴板，并存进 `ans` |
| `↑` / `↓` | 翻之前算过的算式 |
| `Esc` | 第一下清空输入，输入已空时退出程序 |
| `Ctrl+K` | 展开 / 收起底部的符号面板 |
| `Ctrl+C` | 有选中就复制选中的字，没选中就复制结果 |
| `Ctrl+滚轮` | 整体放大 / 缩小（0.7 ~ 2.0 倍），也可以用 `Ctrl+加号` / `Ctrl+减号` |
| `Ctrl+0` | 宽度和倍率都恢复默认 |
| `Ctrl+M` | 切换单行 / 多行模式 |
| 右键 | 菜单：复制结果 / 清空 / 面板 / 恢复默认大小 / 多行模式 / 总在最前 / 清除变量 / 退出 |

窗口没有标题栏，**在空白处按住就能拖**。

### 改大小

两个方向分开调，互不干扰：

- **改宽度**：鼠标移到窗口**左右边缘**，光标变成 `↔` 就能按住拖。字号不变，只是一行能装下更长的算式；
  底部面板里的按钮会跟着重新换行。拖左边缘时右边界钉住不动。最窄 380、最宽到显示器边。
- **改大小**：`Ctrl+滚轮`，整个界面按比例缩放 —— 字、图标、按钮、行高一起变。

位置、宽度、缩放倍率、历史、面板开合都记在 exe 旁边的 `calcbar.json` 里。宽度存的是「逻辑像素」，
所以把窗口拖到另一块不同 DPI 的屏幕上，看起来还是一样大。万一调乱了，`Ctrl+0` 一键复位。

## 算式规则（就是 Python）

| 写法 | 结果 | 说明 |
| --- | --- | --- |
| `2**3` | `8` | 乘方是 `**` |
| `2*3` | `6` | |
| `10//3` | `3` | 整除 |
| `10%3` | `1` | 取余 |
| `4/2` | `2.0` | 真除法出小数，和 Python 一致 |
| `0.1+0.2` | `0.30000000000000004` | 浮点数就是这样，不替你四舍五入 |
| `2**100` | `1267650600228229401496703205376` | 大整数精确 |
| `2>1` | `True` | 比较也能算 |

两个容易踩的地方，都是 Python 本身的规则：

- **`^` 是按位异或，不是乘方**，所以 `2^3` 得 `1`。输入里出现 `^` 时，结果后面会自动提醒你一句「乘方请用 `**`」。
- **`round` 是「四舍六入五成双」**，正好是 `.5` 时向偶数取整：
  `round(0.5)=0`、`round(1.5)=2`、`round(2.5)=2`、`round(3.5)=4`。
  这是 IEEE 754 的默认舍入方式，为的是让大批数据求和时误差不会一直往上偏。
  想要老式的四舍五入，用 `floor(x+0.5)`。
  另外 `round(2.675, 2)` 得 `2.67` 而不是 `2.68`，因为 2.675 存成二进制其实略小于 2.675。

### 函数和常量

`math` 里的东西直接用，不用前缀：

```
sqrt(16)        4.0
tanh(2)         0.9640275800758169
log(100, 10)    2.0
factorial(10)   3628800
degrees(pi)     180.0
hypot(3, 4)     5.0
gcd(12, 18)     6
pi  e  tau  inf  nan
```

另外还有 `abs round min max sum pow divmod int float complex bool len bin hex oct sorted range`，
以及一个别名 `ln`（= 自然对数）。

复数按 Python 写：`3+4j`、`abs(3+4j)` 得 `5.0`。`j` 单独写也认（就是 `1j`），所以面板上的 `j` 按钮
放在哪个位置点都成立。

### 变量和 ans

```
x = 5           →  x = 5
x**2            →  25
ans+1           →  26      (ans 是上一次按 Enter 的结果)
```

右键菜单里的「清除自定义变量」可以把它们清掉，**`ans` 也会一起归零**。变量只在内存里，
关掉程序就没了，不会写进 `calcbar.json`。想单独改一个变量，直接重新赋值（`x = 0`）即可 ——
`del x` 是不支持的写法。

## 多行模式（`Ctrl+M`）

一步一行，**共用一套变量**，结果排在右边一列：

```
r = 3
h = 10
show base = pi*r**2      = 28.274333882308138
show v = base*h          = 282.7433388230814
v/3                      = 94.2477796076938
```

规则就四条：

- **默认只显示最后一行的结果**，中间步骤照常执行、但不显示，免得刷屏。
- **想看哪一步，就在那行开头写 `show`。** 两种写法都行，随你顺手：

  ```
  show b            两个都一样
  show(b)
  ```

  赋值行只显示值（变量名就在左边摆着，不必重复）。
- **算错的行一定会说话**，哪怕没写 `show` —— 出错还闷着不吭声是最坑人的。
- **某一行算错不影响后面的行**，那行就地显示红字，其余照算。而「还没打完」（`b=a**`、
  刚打到一半的 `sqr`）不算错，仍然安静，不会边打边飘红。

`show` 不是保留字：`show = 5`、`show * 2` 这样把它当普通变量用照样可以。只有「`show` 后面
跟着一个完整算式」才当关键字。

| 按键 | 多行模式下 |
| --- | --- |
| `Enter` | 换行 |
| `Ctrl+Enter` | 复制**最后一行**的值，并存进 `ans` |
| `↑` / `↓` | 移动光标 |
| `Ctrl+↑` / `Ctrl+↓` | 翻历史（多行历史存的是整块草稿，跟单行历史分开） |

窗口高度跟着行数长，超过 12 行就固定下来、在框里滚动；最多算 40 行（每敲一个键要重算整份）。
**两种模式各留各的草稿**：切过去是空白的，切回来内容还在。当前模式记在 `calcbar.json` 里。

### 不好输入的符号

底部面板（点右边的计算器按钮，或按 `Ctrl+K`）里点一下就插进去，函数会自动带括号并把光标放进去。
面板里的按钮插入的是 Python 写法（点 `π` 插入的是 `pi`），复制出去可以直接粘到代码里。

如果你从别处粘进来的算式带这些符号，也能直接认：

| 你输入 | 等价于 |
| --- | --- |
| `×` `·` | `*` |
| `÷` | `/` |
| `−`（长横） | `-` |
| `π` `τ` `∞` | `pi` `tau` `inf` |
| `√9` `√(3+6)` | `sqrt(9)` `sqrt(3+6)` |
| `∛27` | `cbrt(27)` |
| `3²` `10⁻³` | `3**(2)` `10**(-3)` |
| `≠` `≤` `≥` | `!=` `<=` `>=` |
| 全角 `（１＋２）` | `(1+2)` |

括号少写右边的会自动补上：打 `sqrt(16` 就已经显示 `= 4.0` 了。

## 一些细节

- **只算数，不跑代码。** 表达式先过 AST 白名单：属性访问、`import`、`lambda`、下标、下划线开头的名字统统拒绝，
  求值时的 `__builtins__` 是空的。`__import__("os")`、`().__class__` 这类写法都会被挡下来。
- **不会卡死。** `9**9**9`、`factorial(10**9)` 这种会在计算前按位数估算拦掉——毕竟每敲一个键都要算一次。
- **没打完不报错。** 输入 `2+` 的时候什么都不显示，而不是弹个红色的 SyntaxError 吓人。
  同理，刚点完面板上的 `sqrt()`（光标正停在括号里）、或者手打 `sqrt` 才打到 `sqr` 的时候，也都保持安静。
  但真写错了还是会说：`nosuch(2)` 照样提示「没有叫 nosuch 的函数或变量」。
- **跟随系统深浅色**，高分屏下按显示器 DPI 渲染（不糊）。
- 结果太长会中间省略显示，但 `Enter` 复制出去的永远是完整值。

## 自己改 / 自己打包

```
calcbar/evaluator.py   算式解析与求值（纯逻辑，好测）；多行走 evaluate_script
calcbar/inputbox.py    单行 Entry / 多行 Text 包成同一套接口
calcbar/ui.py          界面
calcbar/symbols.py     面板里有哪些符号和函数
calcbar/theme.py       配色和尺寸（含最小宽度、边缘拉伸判定宽度）
calcbar/icons.py       图标绘制（Pillow）
calcbar/winapi.py      DPI / 圆角 / 剪贴板 / 深浅色
```

- 从源码跑：装了 Python 3.10+ 就双击 `run.bat`（或 `pythonw CalcBar.pyw`）。
  Pillow 是可选的，没装只是图标退化成简笔画，功能不受影响。
- 跑测试：双击 `test.bat`（175 个用例；界面测试会在屏幕上闪一下窗口，正常现象）。
  其中 `tests/test_formulas.py` 专门核对面板里每个公式：参照物一律另找（闭式解、暴力枚举、
  恒等式、Decimal 高精度、跟原生 Python 差分），而不是拿 `math.xxx` 自己验自己。
- 重新打包：`pip install pyinstaller pillow` 之后双击 `build.bat`，产物在 `dist\CalcBar.exe`。

窗口圆角用的是 Windows 11 的 DWM 接口。在 Windows 10 上圆角会退化成直角，其余功能正常。
