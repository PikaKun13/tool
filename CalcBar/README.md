# CalcBar

Spotlight 風の電卓バー。**式は Python の書き方で、math の関数に `math.` は不要**です。

```
🔍  27*27          = 729
🔍  2**3           = 8
🔍  tanh(2)        = 0.9640275800758169
🔍  (1+2)*(3+4)    = 21
🔍  sqrt(2)/2      = 0.7071067811865476
```

ポータブル版は `dist\CalcBar.exe` の単一ファイルで、どこにコピーしてもダブルクリックで動きます。**Python のインストールは不要**で、レジストリも書き換えません。
Python 3.12 のランタイムを同梱しているので 18 MB あります。この exe は `build.bat` の生成物で、**git には入れていません**
（18 MB のバイナリは一度履歴に入れると二度と消せないため）。`build.bat` を一度実行すれば作れます。

> ウィンドウは枠なしなので、**タスクバーにボタンは出ません**（Spotlight と同じ）。exe ファイル自体にはアイコンがあります。
> エクスプローラーで白紙のアイコンになっている場合は、Windows のアイコンキャッシュが古いだけです。別のフォルダーで見るか、エクスプローラーを再起動してください。

---

## 使い方

`dist\CalcBar.exe` をダブルクリック（Python が入っていれば `run.bat` でも可）すると、入力欄に自動でフォーカスが当たります。
**入力しながら結果が出て**、グレーの `= 結果` が式のすぐ後ろに表示されます。

| キー | 動作 |
| --- | --- |
| `Enter` | 結果をクリップボードにコピーし、`ans` に保存 |
| `↑` / `↓` | 以前に計算した式をたどる |
| `Esc` | 1 回目で入力をクリア、入力が空なら終了 |
| `Ctrl+K` | 下部の記号パネルを開く / 閉じる |
| `Ctrl+C` | 選択範囲があればその文字を、なければ結果をコピー |
| `Ctrl+ホイール` | 全体を拡大 / 縮小（0.7〜2.0 倍）。`Ctrl+プラス` / `Ctrl+マイナス` でも可 |
| `Ctrl+0` | 幅と倍率をどちらも既定値に戻す |
| `Ctrl+M` | 1 行 / 複数行モードの切り替え |
| 右クリック | メニュー：結果をコピー / クリア / 記号パネル / 既定のサイズに戻す / 複数行モード / 常に手前に表示 / カスタム変数のクリア / 終了 |

ウィンドウにタイトルバーはありません。**何もないところを押さえたままドラッグすれば動かせます**。

### サイズの変更

2 つの方向は別々に調整でき、互いに影響しません。

- **幅を変える**：ウィンドウの**左右の端**にマウスを持っていき、カーソルが `↔` になったらドラッグします。文字の大きさはそのままで、1 行に入る式が長くなるだけです。
  下部パネルのボタンも合わせて折り返し直されます。左端をドラッグしたときは右端が固定されます。最小 380、最大はディスプレイの端まで。
- **大きさを変える**：`Ctrl+ホイール` で、画面全体が比率を保ったまま拡大縮小します。文字、アイコン、ボタン、行の高さがまとめて変わります。

位置、幅、拡大率、履歴、パネルの開閉は exe と同じフォルダーの `calcbar.json` に保存されます。幅は「論理ピクセル」で保存しているので、
DPI の違う別のディスプレイにウィンドウを移しても見た目の大きさは変わりません。おかしくなったら `Ctrl+0` で一発リセットできます。

## 式のルール（Python そのもの）

| 書き方 | 結果 | 説明 |
| --- | --- | --- |
| `2**3` | `8` | べき乗は `**` |
| `2*3` | `6` | |
| `10//3` | `3` | 切り捨て除算 |
| `10%3` | `1` | 剰余 |
| `4/2` | `2.0` | ふつうの割り算は小数になる（Python と同じ） |
| `0.1+0.2` | `0.30000000000000004` | 浮動小数点数はこういうもの。勝手に丸めない |
| `2**100` | `1267650600228229401496703205376` | 大きな整数も正確 |
| `2>1` | `True` | 比較もできる |

つまずきやすい点が 2 つあります。どちらも Python 自体のルールです。

- **`^` はビットごとの排他的論理和で、べき乗ではありません**。なので `2^3` は `1` になります。入力に `^` があると、結果の後ろに「べき乗は `**` で」という注意が自動で出ます。
- **`round` は「偶数丸め」**で、ちょうど `.5` のときは偶数側に丸めます：
  `round(0.5)=0`、`round(1.5)=2`、`round(2.5)=2`、`round(3.5)=4`。
  これは IEEE 754 の既定の丸め方で、大量のデータを合計したときに誤差が一方向に偏らないようにするためです。
  昔ながらの四捨五入がほしいときは `floor(x+0.5)` を使ってください。
  また `round(2.675, 2)` が `2.68` ではなく `2.67` になるのは、2.675 を 2 進数で表すと実際には 2.675 よりわずかに小さいからです。

### 関数と定数

`math` にあるものは接頭辞なしでそのまま使えます：

```
sqrt(16)        4.0
tanh(2)         0.9640275800758169
log(100, 10)    2.0
factorial(10)   3628800
degrees(pi)     180.0
hypot(3, 4)     5.0
gcd(12, 18)     6
pi  e  tau  inf  nan
```

ほかに `abs round min max sum pow divmod int float complex bool len bin hex oct sorted range`、
それに別名の `ln`（＝自然対数）があります。

複素数は Python の書き方で：`3+4j`、`abs(3+4j)` は `5.0`。`j` 単体でも通じる（`1j` のこと）ので、パネルの `j` ボタンは
どの位置で押しても式として成立します。

### 変数と ans

```
x = 5           →  x = 5
x**2            →  25
ans+1           →  26      (ans は直前に Enter したときの結果)
```

右クリックメニューの「カスタム変数のクリア」で消せます。**`ans` も一緒に 0 に戻ります**。変数はメモリ上にあるだけで、
プログラムを閉じると消え、`calcbar.json` には書き込まれません。1 つの変数だけ変えたいときは、そのまま代入し直してください（`x = 0`）。
`del x` という書き方には対応していません。

## 複数行モード（`Ctrl+M`）

1 行に 1 ステップずつ書き、**変数は全行で共有**されます。結果は右側に 1 列で並びます：

```
r = 3
h = 10
show base = pi*r**2      = 28.274333882308138
show v = base*h          = 282.7433388230814
v/3                      = 94.2477796076938
```

ルールは 4 つだけです：

- **既定では最後の行の結果だけを表示します**。途中のステップもふつうに実行されますが、画面が埋まらないよう表示はしません。
- **見たいステップは、その行の先頭に `show` と書きます。** 書き方は 2 通りあり、好きなほうで構いません：

  ```
  show b            どちらも同じ
  show(b)
  ```

  代入の行は値だけを表示します（変数名はすぐ左に書いてあるので繰り返しません）。
- **エラーになった行は必ず知らせます**。`show` がなくてもです。エラーなのに黙っているのがいちばん困るので。
- **ある行がエラーでも後ろの行には影響しません**。その行にだけ赤字が出て、ほかはそのまま計算されます。ただし「まだ書きかけ」（`b=a**`、
  途中まで打った `sqr`）はエラー扱いせず静かなままなので、入力中に赤字がちらつくことはありません。

`show` は予約語ではありません。`show = 5`、`show * 2` のようにふつうの変数としても使えます。「`show` の後ろに
完全な式が続く」ときだけキーワードとして扱います。

| キー | 複数行モードでは |
| --- | --- |
| `Enter` | 改行 |
| `Ctrl+Enter` | **最後の行**の値をコピーし、`ans` に保存 |
| `↑` / `↓` | カーソル移動 |
| `Ctrl+↑` / `Ctrl+↓` | 履歴をたどる（複数行の履歴は下書きのブロック全体を保存し、1 行モードの履歴とは別） |

ウィンドウの高さは行数に合わせて伸び、12 行を超えると固定されて枠の中でスクロールします。計算できるのは最大 40 行です（キーを 1 つ打つたびに全体を再計算するため）。
**2 つのモードはそれぞれ別の下書きを持ちます**：切り替えた先は空で、戻ると内容が残っています。現在のモードは `calcbar.json` に保存されます。

### 入力しにくい記号

下部のパネル（右側の電卓ボタンをクリック、または `Ctrl+K`）でクリックすれば挿入できます。関数は括弧つきで入り、カーソルが括弧の中に置かれます。
パネルのボタンが挿入するのは Python の書き方（`π` を押すと `pi` が入る）なので、コピーしてそのままコードに貼れます。

ほかから貼り付けた式にこれらの記号が入っていても、そのまま認識します：

| 入力 | 同じ意味 |
| --- | --- |
| `×` `·` | `*` |
| `÷` | `/` |
| `−`（長い横棒） | `-` |
| `π` `τ` `∞` | `pi` `tau` `inf` |
| `√9` `√(3+6)` | `sqrt(9)` `sqrt(3+6)` |
| `∛27` | `cbrt(27)` |
| `3²` `10⁻³` | `3**(2)` `10**(-3)` |
| `≠` `≤` `≥` | `!=` `<=` `>=` |
| 全角 `（１＋２）` | `(1+2)` |

閉じ括弧を書き忘れても自動で補います：`sqrt(16` と打った時点で `= 4.0` が表示されます。

## 細かいこと

- **計算するだけで、コードは実行しません。** 式はまず AST のホワイトリストを通します。属性アクセス、`import`、`lambda`、添字、アンダースコアで始まる名前はすべて拒否し、
  評価時の `__builtins__` は空です。`__import__("os")` や `().__class__` のような書き方はすべてはじかれます。
- **固まりません。** `9**9**9`、`factorial(10**9)` のようなものは、計算する前に桁数を見積もって止めます。キーを 1 つ打つたびに計算するためです。
- **書きかけではエラーを出しません。** `2+` と入力している間は何も表示せず、赤い SyntaxError で驚かせたりしません。
  同様に、パネルで `sqrt()` を押した直後（カーソルが括弧の中にあるとき）や、手で `sqrt` を打っていてまだ `sqr` までのときも静かなままです。
  ただし本当に間違っているときはちゃんと知らせます：`nosuch(2)` なら、nosuch という名前の関数や変数はないと表示します。
- **システムのライト / ダークモードに追従**し、高 DPI の画面ではディスプレイの DPI に合わせて描画します（ぼやけません）。
- 結果が長すぎるときは途中を省略して表示しますが、`Enter` でコピーされるのは常に完全な値です。

## 改造とビルド

```
calcbar/evaluator.py   式の解析と評価（純粋なロジックでテストしやすい）。複数行は evaluate_script
calcbar/inputbox.py    1 行の Entry と複数行の Text を同じインターフェースで包む
calcbar/ui.py          画面
calcbar/symbols.py     パネルに並べる記号と関数
calcbar/theme.py       配色とサイズ（最小幅、端のリサイズ判定幅を含む）
calcbar/icons.py       アイコンの描画（Pillow）
calcbar/winapi.py      DPI / 角丸 / クリップボード / ライト・ダーク
```

- ソースから実行：Python 3.10 以上が入っていれば `run.bat` をダブルクリック（または `pythonw CalcBar.pyw`）。
  Pillow は任意です。入っていなければアイコンが簡単な線画になるだけで、機能には影響しません。
- テスト：`test.bat` をダブルクリック（175 ケース。UI テストで画面にウィンドウが一瞬出ますが正常です）。
  そのうち `tests/test_formulas.py` はパネルの各公式を検証するもので、比較対象は必ず別の手段で用意しています（閉形式の解、総当たり、
  恒等式、Decimal による高精度計算、素の Python との差分）。`math.xxx` で自分自身を検証するようなことはしていません。
- 再ビルド：`pip install pyinstaller pillow` のあと `build.bat` をダブルクリックすると、`dist\CalcBar.exe` ができます。

ウィンドウの角丸には Windows 11 の DWM API を使っています。Windows 10 では角丸が直角になりますが、ほかの機能は問題なく動きます。
